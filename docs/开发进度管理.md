## 📝 开发注意事项

### 开发顺序原则

1. **依赖优先**：先开发被依赖的模块（如工具函数、类型定义）
2. **由内而外**：先开发核心功能，再开发界面
3. **由简到繁**：先实现基础功能，再添加高级特性
4. **前后联动**：前端和后端同步开发，确保接口一致

### 每日开发流程

```
1. 查看本文档，确认今天要完成的任务
2. 阅读相关文档（需求、数据库、UI设计）
3. 开发 → 测试 → 验收
4. 完成后在任务前打 ✅
5. 提交代码（commit message 参考 .cursorrules）
```

### 质量标准

- ✅ 代码清晰易读，有必要的注释
- ✅ 类型定义完整，无 TypeScript 错误
- ✅ 样式与设计稿一致（参考 `preview/` 目录）
- ✅ 功能完整，交互流畅
- ✅ 错误处理完善，边界情况考虑周全
- ✅ 响应式设计，移动端适配
- ✅ 性能良好，加载速度快

### 遇到问题怎么办

1. **先查文档**：查看 `docs/` 目录下的相关文档
2. **看预览页**：参考 `preview/` 目录下的 HTML 原型
3. **读规则**：遵循 `.cursorrules` 中的开发规则
4. **全局思考**：考虑修改的影响范围
5. **测试验证**：修改后立即测试相关功能
