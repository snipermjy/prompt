# AI提示词库 - 部署指南

本文档说明如何部署和运行AI提示词库项目。

## 前置要求

- **Node.js**: 18.17 或更高版本
- **npm** 或 **pnpm**: 最新版本
- **Supabase账号**: 用于数据库和后端服务

---

## 本地开发部署

### 1. 安装 Node.js

如果尚未安装 Node.js，请访问 [nodejs.org](https://nodejs.org/) 下载并安装。

验证安装：
```bash
node --version
npm --version
```

### 2. 安装依赖

在项目根目录下运行：

```bash
npm install
# 或
pnpm install
```

### 3. 配置 Supabase

#### 3.1 创建 Supabase 项目

1. 访问 [supabase.com](https://supabase.com)
2. 注册/登录账号
3. 点击 "New Project" 创建新项目
4. 记录以下信息：
   - Project URL
   - API Key (anon, public)
   - Service Role Key (secret)

#### 3.2 创建数据库表

1. 在 Supabase Dashboard 中，进入 "SQL Editor"
2. 复制 `supabase/schema.sql` 文件的内容
3. 粘贴并执行 SQL 脚本
4. 确认所有表创建成功

#### 3.3 插入初始数据（可选）

1. 在 SQL Editor 中，复制 `supabase/seed.sql` 文件的内容
2. 粘贴并执行 SQL 脚本
3. 这将插入分类和测试数据

### 4. 配置环境变量

复制 `.env.example` 为 `.env.local`：

```bash
cp .env.example .env.local
```

编辑 `.env.local`，填入你的 Supabase 配置：

```env
NEXT_PUBLIC_SUPABASE_URL=https://你的项目ID.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=你的anon_key
SUPABASE_SERVICE_ROLE_KEY=你的service_role_key

NEXT_PUBLIC_SITE_URL=http://localhost:3000
```

### 5. 启动开发服务器

```bash
npm run dev
# 或
pnpm dev
```

打开浏览器访问 [http://localhost:3000](http://localhost:3000)

## 生产环境部署（Vercel）

### 方法一：通过 Vercel Dashboard

1. 访问 [vercel.com](https://vercel.com)
2. 注册/登录账号
3. 点击 "Add New Project"
4. 导入你的 Git 仓库
5. 配置环境变量：
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY`
   - `NEXT_PUBLIC_SITE_URL`（你的域名）
6. 点击 "Deploy" 开始部署

### 方法二：通过 Vercel CLI

```bash
# 安装 Vercel CLI
npm i -g vercel

# 登录
vercel login

# 部署
vercel

# 配置环境变量
vercel env add NEXT_PUBLIC_SUPABASE_URL
vercel env add NEXT_PUBLIC_SUPABASE_ANON_KEY
vercel env add SUPABASE_SERVICE_ROLE_KEY
vercel env add NEXT_PUBLIC_SITE_URL

# 重新部署
vercel --prod
```

## 数据库管理

### 查看数据

在 Supabase Dashboard 中：
1. 进入 "Table Editor"
2. 选择表（prompts, categories, user_submissions）
3. 可以直接查看、编辑数据

### 备份数据

在 Supabase Dashboard 中：
1. 进入 "Database" → "Backups"
2. 可以手动创建备份或启用自动备份

### 重置数据

如果需要重置数据库：
1. 删除所有表
2. 重新执行 `supabase/schema.sql`
3. （可选）重新执行 `supabase/seed.sql`

## 常见问题

### 1. 页面显示"暂无数据"

**原因**：数据库中没有数据

**解决方案**：
- 执行 `supabase/seed.sql` 插入测试数据
- 或者通过管理后台手动添加数据

### 2. 环境变量未生效

**原因**：环境变量配置错误或未重启服务器

**解决方案**：
- 确认 `.env.local` 文件存在且配置正确
- 重启开发服务器（`npm run dev`）
- Vercel 部署时确认在 Dashboard 中配置了环境变量

### 3. 数据库连接失败

**原因**：Supabase URL 或 Key 配置错误

**解决方案**：
- 检查 Supabase Dashboard 中的 API 设置
- 确认复制的 URL 和 Key 完全正确
- 确认项目状态为 "Active"

### 4. RLS 策略导致无法读取数据

**原因**：行级安全策略配置问题

**解决方案**：
- 在 Supabase Dashboard 中检查 RLS 策略
- 确认已执行 `supabase/schema.sql` 中的 RLS 配置
- 或临时禁用 RLS 进行测试（不推荐用于生产环境）

## 性能优化建议

### 1. 启用 ISR（增量静态再生）

Next.js 已配置 ISR，可以在 Server Components 中添加：

```typescript
export const revalidate = 3600; // 每小时更新一次
```

### 2. 图片优化

使用 Next.js 的 Image 组件：

```typescript
import Image from 'next/image';

<Image src="/logo.png" alt="Logo" width={100} height={100} />
```

### 3. 数据库索引

已在 `supabase/schema.sql` 中创建必要索引，如需更多索引可自行添加。

### 4. CDN 配置

Vercel 自动提供全球 CDN，无需额外配置。

---

## 安全建议

1. **不要泄露** Service Role Key（仅在服务端使用）
2. **不要提交** `.env.local` 到 Git（已在 `.gitignore` 中）
3. **启用 RLS**：确保所有表都启用了行级安全策略
4. **定期更新依赖**：运行 `npm audit` 检查安全漏洞
