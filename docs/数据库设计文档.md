# AI提示词库 - 数据库设计文档

## 数据库选择

**数据库服务**：Supabase (基于PostgreSQL)  
**免费额度**：500MB数据库 + 1GB文件存储 + 5GB带宽  
**访问方式**：REST API（前端直接调用） + Supabase SDK

## 表结构设计

### 一、prompts（提示词表）

#### 表说明
存储所有提示词的完整信息，包括用户输入内容和AI自动生成的元数据。

#### 字段列表

| 字段名 | 类型 | 约束 | 默认值 | 说明 |
|--------|------|------|--------|------|
| **基础信息** |
| `id` | uuid | PRIMARY KEY | uuid_generate_v4() | 唯一标识符 |
| `content` | text | NOT NULL | - | 提示词完整内容（用户输入） |
| `source` | varchar(20) | NOT NULL | 'admin' | 来源：'admin'（管理员）或 'user_submit'（用户提交） |
| `status` | varchar(20) | NOT NULL | 'draft' | 状态：'draft'（草稿）、'published'（已发布）、'pending_review'（待审核） |
| **AI自动生成字段** |
| `title` | varchar(200) | NULL | - | 提示词标题（AI生成，20字以内） |
| `description` | text | NULL | - | 简短描述（AI生成，50-100字，用于卡片展示） |
| `main_category` | varchar(50) | NULL | - | 主分类（AI生成或从建议列表选择） |
| `sub_category` | varchar(50) | NULL | - | 子分类（AI生成，可为空） |
| `tags` | text[] | NULL | '{}' | 标签数组（AI生成，3-5个） |
| `use_cases` | text[] | NULL | '{}' | 使用场景数组（AI生成，2-3个） |
| `difficulty` | varchar(20) | NULL | - | 难度等级：'beginner'、'intermediate'、'advanced' |
| `prompt_type` | varchar(50) | NULL | - | 提示词类型（AI生成，如"角色扮演"、"写作辅助"等） |
| `language` | varchar(20) | NULL | - | 语言：'zh'（中文）、'en'（英文）、'bilingual'（双语） |
| `target_ai` | text[] | NULL | '{}' | 适用AI模型数组（AI生成，支持任意模型名称，如["ChatGPT", "Claude", "Gemini"]等） |
| `keywords` | text[] | NULL | '{}' | SEO关键词数组（AI生成，用于搜索优化） |
| **统计字段** |
| `view_count` | integer | NOT NULL | 0 | 浏览次数（访问详情页+1） |
| `copy_count` | integer | NOT NULL | 0 | 复制次数（点击复制按钮+1） |
| `share_count` | integer | NOT NULL | 0 | 分享次数（点击分享按钮+1） |
| **用户提交相关** |
| `submitter_email` | varchar(255) | NULL | - | 提交者邮箱（用户提交时可选填，用于接收审核通知） |
| `admin_notes` | text | NULL | - | 管理员备注（审核时可添加备注信息） |
| **来源信息** |
| `author_name` | varchar(100) | NULL | - | 来源作者名称（自媒体账号名称，用于感谢原作者） |
| `author_link` | varchar(500) | NULL | - | 来源作者链接（自媒体账号链接，点击可跳转） |
| **时间戳** |
| `created_at` | timestamptz | NOT NULL | now() | 创建时间 |
| `updated_at` | timestamptz | NOT NULL | now() | 更新时间 |
| `published_at` | timestamptz | NULL | - | 发布时间（状态改为published时设置） |

#### 索引设计

```sql
-- 主键索引（自动创建）
PRIMARY KEY (id)

-- 状态索引（用于筛选已发布/待审核）
CREATE INDEX idx_prompts_status ON prompts(status);

-- 分类索引（用于分类筛选）
CREATE INDEX idx_prompts_main_category ON prompts(main_category);

-- 标签GIN索引（用于数组搜索）
CREATE INDEX idx_prompts_tags ON prompts USING GIN(tags);

-- 时间索引（用于按最新排序）
CREATE INDEX idx_prompts_created_at ON prompts(created_at DESC);

-- 浏览次数索引（用于按热度排序）
CREATE INDEX idx_prompts_view_count ON prompts(view_count DESC);

-- 全文搜索索引（用于搜索标题、描述、关键词）
CREATE INDEX idx_prompts_search ON prompts 
USING GIN(to_tsvector('chinese', coalesce(title, '') || ' ' || coalesce(description, '') || ' ' || array_to_string(keywords, ' ')));

-- 复合索引（状态+发布时间，用于前端查询已发布的提示词）
CREATE INDEX idx_prompts_status_published_at ON prompts(status, published_at DESC);
```

#### 触发器

```sql
-- 自动更新 updated_at 字段
CREATE OR REPLACE FUNCTION update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = now();
    RETURN NEW;
END;
$$ language 'plpgsql';

CREATE TRIGGER update_prompts_updated_at BEFORE UPDATE ON prompts
FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();

-- 自动设置 published_at（当状态改为published时）
CREATE OR REPLACE FUNCTION set_published_at()
RETURNS TRIGGER AS $$
BEGIN
    IF NEW.status = 'published' AND OLD.status != 'published' THEN
        NEW.published_at = now();
    END IF;
    RETURN NEW;
END;
$$ language 'plpgsql';

CREATE TRIGGER set_prompts_published_at BEFORE UPDATE ON prompts
FOR EACH ROW EXECUTE FUNCTION set_published_at();
```

#### RLS（行级安全）策略

```sql
-- 启用RLS
ALTER TABLE prompts ENABLE ROW LEVEL SECURITY;

-- 公众用户只能查看已发布的提示词
CREATE POLICY "公众可查看已发布提示词" ON prompts
FOR SELECT
USING (status = 'published');

-- 使用service role key可以进行所有操作（管理后台使用）
-- 注意：service role key跳过RLS，需要在后端妥善保管
```

### 二、categories（分类表）

#### 表说明
存储所有分类信息，支持两级分类（主分类和子分类）。

#### 字段列表

| 字段名 | 类型 | 约束 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `id` | uuid | PRIMARY KEY | uuid_generate_v4() | 唯一标识符 |
| `name` | varchar(50) | NOT NULL UNIQUE | - | 分类名称（唯一） |
| `parent_id` | uuid | FOREIGN KEY | NULL | 父分类ID（主分类为NULL，子分类指向父分类） |
| `description` | text | NULL | - | 分类描述 |
| `icon` | varchar(50) | NULL | - | 图标名称（Lucide Icons图标名） |
| `sort_order` | integer | NOT NULL | 0 | 排序权重（数字越小越靠前） |
| `created_at` | timestamptz | NOT NULL | now() | 创建时间 |
| `updated_at` | timestamptz | NOT NULL | now() | 更新时间 |

#### 索引设计

```sql
-- 主键索引（自动创建）
PRIMARY KEY (id)

-- 唯一索引（分类名称不能重复）
UNIQUE (name)

-- 父分类索引（用于查询子分类）
CREATE INDEX idx_categories_parent_id ON categories(parent_id);

-- 排序索引
CREATE INDEX idx_categories_sort_order ON categories(sort_order ASC);
```

#### 外键约束

```sql
-- 父分类外键（自引用）
ALTER TABLE categories 
ADD CONSTRAINT fk_categories_parent 
FOREIGN KEY (parent_id) REFERENCES categories(id) ON DELETE CASCADE;
```

#### 触发器

```sql
-- 自动更新 updated_at
CREATE TRIGGER update_categories_updated_at BEFORE UPDATE ON categories
FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();
```

### 三、settings（全局配置表）

#### 表说明
存储网站的全局配置信息，单行表（只有一条记录）。

#### 字段列表

| 字段名 | 类型 | 约束 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `id` | integer | PRIMARY KEY | 1 | 固定为1（确保只有一条记录） |
| **用户提交配置** |
| `allow_user_submit` | boolean | NOT NULL | true | 是否允许用户提交提示词 |
| `submit_notice` | text | NULL | - | 提交页面的提示文字 |
| **网站基本信息** |
| `site_title` | varchar(100) | NULL | 'AI提示词库' | 网站标题（用于SEO） |
| `site_description` | text | NULL | - | 网站描述（用于SEO） |
| `site_keywords` | text | NULL | - | 网站关键词（用于SEO，逗号分隔） |
| `announcement` | text | NULL | - | 公告内容（显示在首页顶部，可为空） |
| **分类建议列表** |
| `suggested_categories` | text[] | NULL | - | AI生成分类时的建议列表（已改为使用categories表） |

## 表关系图

```
categories (分类表)
    ├── id (PK)
    └── parent_id (FK -> categories.id)  自引用，支持两级分类
        
prompts (提示词表)
    ├── id (PK)
    ├── main_category -> 字符串（不使用外键，因为AI可能生成新分类）
    └── sub_category -> 字符串（可为空）

settings (配置表)
    └── id = 1 (单行表)
```

**说明**：
- `prompts.main_category` 不使用外键关联 `categories.name`，因为AI可能生成新分类
- 管理员在后台可以手动调整AI生成的分类，并创建新的分类记录
- 前端显示分类时，优先使用 `categories` 表中的分类

## 数据库视图（可选）

### 热门提示词视图

```sql
CREATE VIEW popular_prompts AS
SELECT 
    id,
    title,
    description,
    main_category,
    tags,
    view_count,
    copy_count,
    share_count,
    (view_count + copy_count * 3 + share_count * 5) AS popularity_score
FROM prompts
WHERE status = 'published'
ORDER BY popularity_score DESC;
```

### 分类统计视图

```sql
CREATE VIEW category_stats AS
SELECT 
    main_category,
    COUNT(*) AS prompt_count,
    SUM(view_count) AS total_views
FROM prompts
WHERE status = 'published'
GROUP BY main_category
ORDER BY prompt_count DESC;
```

## 性能优化建议

### 1. 查询优化
- 前端查询时只选择必要字段，避免 `SELECT *`
- 使用分页查询，每页20-50条
- 利用索引优化常用查询

### 2. 缓存策略
- 使用 React Query 缓存查询结果（5分钟）
- 分类列表缓存时间较长（1小时）
- Vercel Edge缓存静态页面

### 3. 统计更新
- 浏览/复制/分享次数采用异步更新
- 避免阻塞用户操作
- 可以考虑批量更新（积累一定数量再写入）

### 4. 全文搜索优化
- 使用 PostgreSQL 的 `ts_vector` 和 `ts_query`
- 中文分词使用 `zhparser` 插件（Supabase支持）
- 搜索结果限制在前100条
