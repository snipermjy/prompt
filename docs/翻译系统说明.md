# 多语言翻译系统说明

## 系统架构

本项目采用**界面语言**和**内容语言**分离的架构：

### 1. 界面语言（UI Language）
- 由 `next-intl` 管理
- 控制按钮、标签、菜单等界面元素的语言
- 配置文件：`locales/zh.json` 和 `locales/en.json`

### 2. 内容语言（Content Language）
- 由数据库翻译表管理
- 控制提示词、分类等用户生成内容的语言
- 数据表：
  - `prompt_translations` - 提示词翻译
  - `category_translations` - 分类翻译

## 工作原理

### 中文界面（/zh）
- 界面元素：显示中文
- 提示词内容：显示原始中文内容（从 `prompts` 表）
- 分类：显示原始中文名称（从 `categories` 表）

### 英文界面（/en）
- 界面元素：显示英文
- 提示词内容：显示英文翻译（从 `prompt_translations` 表）
- 分类：显示英文翻译（从 `category_translations` 表）
- **如果没有翻译**：回退显示原始中文内容

## 添加翻译数据

### 方法 1：使用 SQL 脚本（批量添加）

1. 运行翻译种子数据：
```bash
# 在 Supabase 控制台的 SQL Editor 中运行
supabase/seed_translations.sql
```

### 方法 2：通过管理后台（单个添加）

1. 访问管理后台：`http://localhost:3000/admin`
2. 进入提示词管理
3. 编辑提示词，添加英文翻译

### 方法 3：使用 API（程序化添加）

```typescript
import { upsertPromptTranslation } from '@/app/actions/translations';

await upsertPromptTranslation({
  prompt_id: 'xxx-xxx-xxx',
  locale: 'en',
  title: 'English Title',
  content: 'English Content',
  description: 'English Description',
  translation_status: 'published',
  translated_by: 'ai'
});
```

## 翻译状态

翻译记录有以下状态：

- `pending` - 待翻译
- `ai_translated` - AI 已翻译（待审核）
- `reviewed` - 已审核
- `published` - 已发布（显示给用户）

## 注意事项

- 翻译数据存储在独立的表中，不影响原始数据
- 删除提示词时，相关翻译会自动级联删除（ON DELETE CASCADE）
- 每个提示词-语言组合只能有一条翻译记录（UNIQUE 约束）
