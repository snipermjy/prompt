# AI提示词库 - 项目需求文档

## 项目概述

一个面向公众的AI提示词分享平台，用户可以浏览、搜索、复制各类AI提示词。管理员通过本地后台添加和管理提示词，AI自动生成分类、标签等元数据。

---

## 一、项目定位

### 目标用户
- **主要用户**：需要AI提示词的公众用户
- **管理员**：项目维护者（您本人）

### 核心价值
- 提供优质的AI提示词资源库
- AI自动化分类和标签，降低管理成本
- 良好的搜索和浏览体验
- 强大的SEO优化，提升曝光度

---

## 二、功能需求

### 2.1 公众前端功能

#### 2.1.1 首页
- **布局**：左右布局
  - 左侧：分类导航栏
  - 右侧：提示词卡片网格展示
- **展示内容**：
  - Logo和搜索框
  - 最新/热门提示词
  - 按分类展示
- **响应式**：支持手机、平板、电脑

#### 2.1.2 提示词展示
- **卡片样式**：简洁风格
  - 标题
  - 简短描述（1-2行，超出显示省略号）
  - 主分类标签
  - 2-3个主要标签
  - 浏览次数（显示热度）
  - 来源信息（如果有）：显示作者名称，点击可跳转到作者链接
- **加载方式**：无限滚动（滚动到底部自动加载更多）
- **性能优化**：虚拟滚动 + 缓存

#### 2.1.3 搜索功能
- **类型**：基础搜索
- **搜索范围**：标题、标签、描述中的关键词
- **技术实现**：Supabase全文搜索
- **排序**：
  - 最新发布
  - 最热门（按浏览/复制次数）
  - 相关度

#### 2.1.4 分类和筛选
- **分类层级**：最多两级
  - 主分类
  - 子分类（可选）
- **筛选方式**：
  - 按主分类筛选
  - 按标签筛选
  - 按难度筛选（新手/中级/高级）
- **分类列表**：
  - 写作辅助
  - 编程开发
  - 营销文案
  - 图像生成
  - 数据分析
  - 学习教育
  - 角色扮演
  - 创意设计
  - 办公效率
  - 其他

#### 2.1.5 提示词详情页
- **展示内容**：
  - 完整提示词内容
  - 标题和描述
  - 分类和标签
  - 使用场景
  - 适用AI模型
  - 难度等级
  - 浏览/复制/分享统计
  - 来源信息（如果有）：显示"来源：@作者名称"，点击可跳转到作者链接
- **交互功能**：
  - 一键复制按钮
  - 复制分享链接按钮
  - 相关推荐（同分类或标签）
- **统计**：
  - 浏览次数自动+1
  - 复制时次数+1
  - 分享时次数+1

#### 2.1.6 用户提交功能
- **开关控制**：管理员可在后台开启/关闭
- **提交表单**：
  - 提示词内容（必填）
  - 邮箱（选填）
    - 如果填写：接收审核结果通知
    - 如果不填：不接收通知
- **提交流程**：
  - 用户提交 → 状态为"待审核"
  - 管理员审核 → 批准/拒绝/编辑后发布
  - 如果留了邮箱 → 发送审核结果通知

#### 2.1.7 其他页面
- **分类页**：展示某个分类下的所有提示词
- **标签页**：展示某个标签下的所有提示词

---

### 2.2 管理后台功能

#### 2.2.1 访问方式
- **运行环境**：本地运行（不部署到公网）
- **访问地址**：`http://localhost:3001/admin`（示例）
- **安全性**：无需密码，仅本地访问

#### 2.2.2 提示词管理
- **列表功能**：
  - 查看所有提示词
  - 搜索和筛选
  - 批量操作（批量删除、批量发布等）
  - 状态筛选（草稿/已发布/待审核）
  
- **添加提示词**：
  1. 粘贴或输入提示词内容
  2. 点击"AI生成"按钮
  3. AI自动生成：标题、描述、分类、标签、使用场景等
  4. 预览AI生成的内容
  5. 手动编辑和调整
  6. 保存（草稿或直接发布）

- **编辑提示词**：
  - 修改所有字段
  - 重新调用AI生成
  - 修改状态（草稿/发布）

- **删除提示词**：
  - 真删除（不保留记录）
  - 支持批量删除

#### 2.2.3 用户提交审核
- **待审核列表**：
  - 显示所有待审核提示词
  - 查看提交内容和提交者邮箱（如有）
  
- **审核操作**：
  - ✅ **批准发布**：直接发布
  - ✏️ **编辑后发布**：修改内容后发布
  - ❌ **拒绝**：删除提交
  
- **通知发送**：
  - 如果提交者留了邮箱，发送审核结果

#### 2.2.4 分类管理
- **添加分类**：
  - 创建主分类
  - 创建子分类（选择父分类）
  
- **编辑分类**：
  - 修改名称和描述
  - 调整排序
  - 设置图标（可选）
  
- **删除分类**：
  - 检查是否有提示词使用该分类
  - 删除或合并到其他分类

- **初始分类**：
  - 系统预置建议分类列表
  - AI生成分类时优先匹配现有分类
  - AI也可以创建新分类（如果现有分类不合适）

#### 2.2.5 配置管理
- **用户提交开关**：
  - 开启/关闭用户提交功能
  - 设置提交页面提示文字
  
- **网站基本信息**：
  - 网站标题
  - 网站描述
  - 网站关键词
  - 公告内容（可选）
  
- **AI服务配置**：
  - DeepSeek API密钥
  - API基础URL
  - 模型名称
  - （存储在环境变量，不在数据库）

#### 2.2.6 统计面板（可选）
- 总提示词数量
- 待审核数量
- 今日新增
- 热门TOP10

### 2.3 AI自动生成功能

#### 2.3.1 生成时机
- 管理员添加提示词时，点击"AI生成"按钮
- 用户提交的内容（可选：自动生成或审核时生成）

#### 2.3.2 生成内容
基于提示词内容，AI自动分析并生成：

| 字段 | 说明 | 示例 |
|------|------|------|
| **title** | 标题（20字以内） | "小红书爆款文案生成器" |
| **description** | 简短描述（50-100字） | "专为小红书平台设计的文案生成提示词..." |
| **main_category** | 主分类 | "营销文案" |
| **sub_category** | 子分类（可选） | "社交媒体" |
| **tags** | 标签（3-5个） | ["小红书", "文案", "营销"] |
| **use_cases** | 使用场景（2-3个） | ["电商推广", "个人IP打造"] |
| **difficulty** | 难度等级 | "beginner" / "intermediate" / "advanced" |
| **prompt_type** | 提示词类型 | "写作辅助" |
| **language** | 语言 | "zh" / "en" / "bilingual" |
| **target_ai** | 适用AI模型 | ["ChatGPT", "Claude", "文心一言"] |
| **keywords** | SEO关键词 | ["小红书文案", "营销文案生成器"] |

#### 2.3.3 分类生成策略
- 优先从建议分类列表中选择匹配的分类
- 如果没有合适的分类，AI可以创建新分类
- 管理员可以手动调整AI生成的分类

#### 2.3.4 AI服务
- **平台**：硅基流动
- **模型**：DeepSeek
- **费用**：不考虑（已有账号）

## 三、技术架构

### 3.1 技术栈

#### 前端技术
- **框架**：Next.js 14 (App Router)
- **UI**：
  - Tailwind CSS（样式）
  - shadcn/ui（组件库）
  - Lucide Icons（图标）
- **状态管理**：React Query（数据缓存）
- **主题**：浅色模式（优先）

#### 后端技术
- **数据库**：Supabase (PostgreSQL)
- **API**：
  - Supabase REST API（前端直接调用）
  - Next.js API Routes（管理后台、AI生成）
- **AI服务**：硅基流动 DeepSeek API

#### 部署方案
- **前端**：Vercel部署
- **管理后台**：本地运行
- **数据库**：Supabase云端（免费套餐）
- **域名**：用户已有

### 3.4 数据流

#### 公众用户浏览
```
用户浏览器 → Vercel前端 → Supabase数据库（只读）
```

#### 管理员添加提示词
```
管理后台 → 调用AI API → 生成元数据 → 保存到Supabase
```

#### 用户提交
```
提交表单 → Next.js API → Supabase（待审核状态）
管理后台 → 审核 → 更新状态 → （可选）发送邮件通知
```

## 四、SEO优化

### 4.1 页面优化
- **Meta标签**：每个页面动态生成title、description、keywords
- **Open Graph**：支持社交媒体分享预览
- **结构化数据**：JSON-LD格式，提升搜索引擎理解
- **语义化HTML**：合理使用h1、h2、article等标签

### 4.2 性能优化
- **图片优化**：Next.js Image组件
- **代码分割**：动态导入非关键组件
- **缓存策略**：
  - 静态页面ISR（增量静态生成）
  - API响应缓存
  - CDN缓存

### 4.3 搜索引擎友好
- **Sitemap**：自动生成XML sitemap
- **Robots.txt**：配置爬虫规则
- **友好URL**：语义化URL，包含关键词

## 五、性能要求

### 5.1 前端性能
- **首屏加载**：< 2秒
- **无限滚动**：流畅无卡顿
- **虚拟滚动**：支持100+提示词高效渲染

### 5.2 搜索性能
- **搜索响应**：< 500ms
- **全文索引**：Supabase GIN索引
- **分页加载**：每次20条
